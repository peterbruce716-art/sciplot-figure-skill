# SciPlot Figure Skill v2.10.0

## Highlights

- Reduced `SKILL.md` from 47 KB to under 8 KB while keeping the same scientific figure capabilities behind progressive `references/` loading.
- Kept `standard` as the ordinary default, with `quick` for previews and `audit` only for strict/reusable/release evidence.
- Added a fast regression test that caps the main skill entrypoint at 9 KB and verifies the core profile, protocol, and status routing remains present.
- Made canonical release-version checks depend on structured metadata (`VERSION`, `pyproject.toml`, and `agents/openai.yaml`) instead of historical narrative documents.
- Updated package and agent metadata to `2.10.0`.

## Compatibility

No renderer, VisualSpec, data-swap, digitization, reconstruction, or audit-bundle capability is removed by this release. Detailed rules remain available under `references/` and implementation remains under `scripts/`.

Python 3.14 remains the supported runtime.
