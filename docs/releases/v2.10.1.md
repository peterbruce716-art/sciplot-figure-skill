# SciPlot Figure Skill v2.10.1

## Reliability fixes

- Reject duplicate or blank CSV/TSV headers, malformed rows, duplicate JSON keys, and scalar/object values masquerading as measurement series.
- Preserve the caller's VisualSpec across repeated rendering and close renderer-owned figures when drawing or export fails.
- Reject non-SVG XML and zero-page PDFs without allowing mixed-delivery validation to override component failures.
- Correct SVG raster footprint estimates for viewBox coordinates, nonzero origins, absolute units, and extreme finite dimensions. Report invalid or unresolved geometry explicitly.
- Exclude the output ZIP itself and root-level `dist` artifacts from installation packages.

## Compatibility

Python 3.14 remains the supported runtime. No new dependencies or workflow profiles are added. Valid data mappings and embedded raster content in mixed figures remain supported; previously ambiguous or malformed inputs now fail with actionable errors.

SVG footprint checks remain a bounded estimate. Inspect rendered output for complex CSS, nested viewports, transforms, and clipping.

## Installation

Download `sciplot-figure-skill-v2.10.1.zip` from this release. Its root folder contains `SKILL.md`, scripts, references, and metadata. The accompanying `.sha256` file verifies the package; `release_acceptance.json` records the release checks.
